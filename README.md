# 🎯 HitScope

> **数字をもっと面白く。**

HitScopeは、Hit&Blow（Bulls and Cows）の対戦データを分析するWebアプリです。

数字の人気ランキングやパターン分析、共起分析、AIによるおすすめ機能を搭載しています。

また、AIとの対戦機能を追加し、それを分析してさらに強くなれる自己学習する、特に対人間最強のAIを制作することが理念です。
